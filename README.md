# Chassi escolhido

Para o projeto foi escolhido um **chassi 2WD**, composto por:

- 2 rodas;
- 2 motores;
- 1 roda de apoio;
- Base estrutural para fixação dos componentes eletrônicos;
- Fonte de alimentação (pilhas).
